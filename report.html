1一句話

客人傳來的「問活動、問時間、改人數」，先讓小幫手接住。客人真的想約了，小幫手把需求整理好，交給店員。店員不用從頭再問一輪，拿到的是客人改過後的最新版。

A　對話與分工

2這段對話發生了什麼

真實一個教會的青少年團體，想到小琉球體驗浮潛。從 2 月第一次詢問，到 5 月活動結束，大約三個月。

  • 先問店家有沒有接青少年
  • 選定「SUP＋深度浮潛」，問兩項合起來多久、新手行不行
  • 人數一路在變：先說十人以內，後來五位，再更正成六位
  • 時段來回討論，也要配合教練和空拍
  • 店員確認時段後列單，再加訂船票，並提醒行前要帶什麼
  • 活動後，店家傳照片與影片，客人另外問了打工換宿

3客人問了哪幾類事

  1. 活動內容、時長、新手能不能玩
  2. 價格與包含項目
  3. 場次與建議（店員會說出建議的理由）
  4. 預約流程：確認人數與時段、列單、訂金與尾款
  5. 下水前的身體與裝備資料
  6. 代訂：船票、餐廳、接送
  7. 行前須知
  8. 個別身體狀況與裝備疑問
  9. 收據與評論邀請
  10. 打工換宿、氣溫水溫

真實這些問題有規律，大部分是重複的，這就是小幫手能分擔的地方。

4哪些小幫手回，哪些一定轉真人

小幫手可以直接回

  • 活動介紹、時長
  • 場次建議與理由
  • 行前須知
  • 水溫、氣候
  • 評論邀請

待核准價格也能回，但只能用店家核准的現行表。

小幫手收意向，店員確認

  • 日期、人數、活動、希望時段
  • 指定教練、空拍等特別要求
  • 客人改資料時，更新成最新版

推論名額、排班、訂金一律由店員確認。

一律轉真人

  • 11/5 新增店家回覆客人提到自身健康問題、能不能下水
  • 11/5 新增店家回覆確認預約的時間有沒有教練可以接
  • 11/5 新增店家回覆超出正常報價的活動（客製化活動很常見）
  • 訂單、付款、收據、改期、退款
  • 需要通電話才講得清楚的事
  • 打工換宿這類每人都不同的安排
  • 小幫手不確定的任何問題

推論寧可多轉，不要答錯。

B　帳號與口吻研究

5店家的親切感從哪裡來

  • 真實店員回得快，一則訊息講一件事，常連發幾則
  • 真實常用「沒問題！」「好的唷」「幫您列單」，語尾有「唷」「喔」「～～」
  • 真實給建議時會說出理由，例如這個時段比較不熱、還能看夕陽
  • 真實主動體貼：提醒票要收好、問要不要代訂

推論最值得保留的是「知道客人在意什麼，再說出建議的理由」。這串是熟人轉介，對陌生客人的拿捏，還要請店家挑幾段實際的對客回覆一起看。

6兩邊研究合起來，與他們的 IG／FB 公開觀察

兩邊研究怎麼合起來

相同的結論：核心情境、人數修正過程、最後列單的時段、指定教練與空拍需求，兩邊一致，沒有衝突。最值得先試的，是「客人後來改的資料，小幫手能不能記對」。

Codex 這邊的重點：把對話拆成五個階段（第一次詢問、選活動、收意向與調整、訂單與行前、活動後），每一階段對應小幫手與店員怎麼分工。

Claude 這邊的重點：整理出問題類型全表、自動與轉真人的分界、口吻特徵，並列出風險與缺口。

他們的 IG 與 FB，公開看起來是這樣

以下只來自公開頁面，看不到店家後台，所以只說「看起來怎樣」，不說「成效好不好」。完整限制見第 8 章「風險與限制」。
IG約 5,400 位粉絲、近千則貼文，商業帳號FB約 1,900 位追蹤者，推薦率 100%（52 則評論）最近內容以故事型短影音為主，搭配少量圖文

推論他們真正在賣的，不只是潛水課，而是「在小琉球，有人陪你完成一件有意義的事」。貼文主軸是客人的夢想、保育、包容、對這片土地的連結。

三個值得借鑑的地方

  1. 「人物夢想」型影片，互動最強。例如長輩完成人生清單的故事。對小幫手來說，客人問「長輩能不能玩」「新手行不行」時，可以附上對應的故事貼文當見證（連結要店家核准）。
  2. 保育與在地連結。這讓人覺得這家店有價值觀。它是品牌氛圍的來源，不是客服內容。
  3. 用教練和店員各自的口吻寫貼文。可以和 LINE 裡店員的口吻對照，整理出口吻卡。

一個不建議搬進客服的

貼文的抒情語氣。貼文可以長、可以感性；客服要短、清楚、一則講一件事。LINE 裡店員的優點就是短而快，小幫手要學這個。

缺口，也是小幫手最能幫上忙的地方

推論公開貼文裡，我們沒看到「第一次來的客人最想知道的事」：要多久、新手行不行、要帶什麼、怎麼預約。客人只能私訊去問，這正是小幫手要接的量。

給店家的本週一招

在互動最強的那支影片下，加一則置頂留言，用一句話寫「第一次來怎麼預約」，並放上 LINE 或私訊入口。

11/5 新增另一個參考：一家別的商家，用 IG 私訊自動帶客人看商品

這是一位真人客人（不是店家）實際操作一家食品商家的 IG 私訊留下的截圖整理。商家名稱不寫出來，只看它的做法。我們推測它用的是按鈕式的自動回覆工具，沒有實際查證。

流程長這樣

  1. 客人在貼文留言，或回覆限動打關鍵字，商家就私訊過去：「想要看看起司禮盒嗎？（按 Yes）」
  2. 客人按一下 Yes，先收到一句「以下訊息為自動回覆」，說訂單或合作請去 LINE
  3. 接著給一張「2 到 15 人份」並排的對比圖，問「要不要看每一盒更詳細的介紹」
  4. 客人按「快介紹給我看」，收到四張左右滑的輪播卡，每張寫人數、適合的場合
  5. 最後才有「我想看價格」按鈕；另外一直放著「我有問題想問」，想找真人隨時按

它做對的六件事

  1. 推論一次只讓客人按一個鈕，不用打字，幾乎不會卡住
  2. 推論先回答最大的疑問：客人最怕「夠不夠吃」，所以先放對比圖，再一盒一盒講
  3. 推論口氣像真人：「讓我準備一下（搓手）」「不會有草莓啊」
  4. 推論誠實說是自動回覆，並先把期待講清楚
  5. 推論價格放在按鈕後面，客人想看才給
  6. 推論每個畫面都有真人出口，右下角常駐「我有問題想問」

它做得不好，我們要避開的五件事

  1. 自由打的字沒人理：客人回覆限動說了一句行程，截圖裡看不到任何回應
  2. 同一套流程重複問第二次：客人隔天回來，又從頭問「要不要看」
  3. 自動回覆在流程中間亂插：兩輪都先跳一則「訂單請到 LINE」，跟當下要做的事無關
  4. LINE ID 被畫面誤判成銀行帳號，出現「複製銀行帳號」按鈕，容易讓人嚇到
  5. 找真人的入口太隱蔽，只有右下角一個小按鈕

套到酷落，互動示意已經照這樣改

  • 活動改成左右滑的卡片：每張寫適合誰、約多久、包含什麼，並附照片（示意圖取自店家公開貼文，正式版要用店家核准的）
  • 價格放在「我想看價格」按鈕後面，點了交給店員，不由小幫手報
  • 下方常駐「我有問題想問，找真人」，任何時候都能按
  • 看不懂的話一律說「我幫您請店員確認」，並標成待處理，不沉默
  • 客人隔天回來時，不重複問，直接問「上次看的是○○，要繼續預約嗎？」（互動示意主選單的「隔天再回來」可以點點看）

7口吻卡（草稿）

依 LINE 對話中店員的說法整理，樣本有限；下面的示範台詞是新寫的，不是店家說過的話。完整限制見第 8 章「風險與限制」。

一句話：親切、快、短，像一位熟悉小琉球的朋友在幫您安排。

開場11/5 新增店家回覆固定台詞「您好，很高興為您服務」，再表明是自動小幫手，接著問需求，不長篇自我介紹 結尾11/5 新增店家回覆「期待現場接待您喔」 稱呼11/5 新增店家回覆對客人一律用「您」 常用句「沒問題！」「好的唷」「請教…^^」「再麻煩您確認」「幫您列單」 語尾「唷」「喔」「～～」「^^」，表情符號用 😊（店家回覆：店內最常用 ^^ 與 😊），每則最多一個符號類 結構一則一件事；先回答再問；給建議附一句理由；客人改資料就重述最新版 絕對不說11/5 新增店家回覆「不行耶」「不可能」「沒辦法」。原則是儘量想辦法解決，不否定客人 另外不要保證結果、沒核准的價格或名額、貼文式的長篇抒情、假裝是真人

11/5 新增口吻卡五題，店家都回覆了

  • 店家回覆稱呼：對客人用「您」
  • 店家回覆表情符號：店內最常用 ^^ 與 😊
  • 店家回覆見面固定台詞：「您好，很高興為您服務」
  • 店家回覆結尾用語：「期待現場接待您喔」
  • 店家回覆絕對不說：「不行耶」「不可能」「沒辦法」，儘量想辦法解決，不否定客人

推論跟我們從 LINE 看到的相符：常用「唷」「^^」，沒看到台語詞。小幫手遇到做不到的事，不直接說不行，而是「我幫您請店員確認、一起找替代的」。

我們另外擬的安全守則仍保留，請店家有空看一眼：不保證不暈船或絕對安全、不報沒核准的價格或名額、不在對話收健康與付款資料、不假裝是真人、不替教練判斷能不能下水。這五條跟店家說的「不否定客人」不衝突，因為做法是轉給教練確認，不是拒絕。

11/5 新增真實公開留言和私訊，口氣不太一樣。他們在 IG 公開留言回粉絲時比較輕鬆，用「你」，口氣像朋友，例如「歡迎歡迎👏」「還是可以來呀，歡迎！」「歡迎一起來玩呀^^ 期待也透過大海療癒妳」「我也跟你一樣！衛生紙（遞🧻」。LINE 裡對正在預約的客人才用「您」。店家說對客人用「您」，小幫手跟私訊走，公開留言回覆可以更輕鬆。

11/5 新增推論陌生人的留言大多是讚嘆，不是詢問。讀了五支貼文的留言區，看到的多半是「好感動」「好棒」。最接近詢問的是長輩那支影片下一句「開放報名銀髮潛水」，店家回「歡迎歡迎👏」，沒有帶客人去 LINE 或私訊。這是小幫手可以補的位置：公開回一句歡迎，再用私訊接手。

資料量仍然小：LINE 只有一位熟人客人，IG 讀了五支貼文的留言區，所以這些是推測，不代表所有客人。

C　風險、下一步與決定

8風險與限制

資料範圍

  • 推論只有一位客人、一次預約，不能代表所有客人；沒有取消、天候改期、退款等情境
  • 推論這是熟人案例，陌生客人怎麼問，還要補資料
  • 推論文字匯出看不到附件與通話內容

公開內容觀察

  • 推論只來自公開頁面，店家的後台（觸及、完播、轉換）看不到，所以只說「看起來怎樣」，不說「成效好不好」
  • 11/5 新增推論只讀了五支貼文的留言區，沒看到陌生客人在公開留言問價格或預約，客人應該都改走私訊與 LINE，所以「陌生客人怎麼問」仍然缺樣本，建議請店家提供 3～5 段去識別的私訊

口吻卡

  • 推論只依一位熟人客人的對話整理；對話對象是店員，不一定是老闆本人，最後要請老闆確認
  • 示範示範台詞是新寫的，不是店家說過的話

待店家確認與安全

  • 待核准對話裡的價格、時長、保險與參加條件，是當時的說法，要店家確認現行版本
  • 推論價格、安全與預約承諾一旦答錯是真的會出事，所以第一版寧可保守

9下一步，由小到大

  1. 11/5 新增約 30 分鐘訪談：店家回覆已先用書面回了人員、轉真人範圍、稱呼與口吻卡五題；還需要說最常被問哪五件事、現在有哪些活動與價格以哪一份為準
  2. 補 3～5 段陌生客人的 IG 私訊（先去掉個資）
  3. 做能點的手機模擬，由店家直接指出哪句像你們、哪句不對、哪一步要叫店員（就是上面那個互動示意）
  4. 店家核准後，才測 IG 收發：先用測試帳號走完問答與人工接手，再決定要不要小範圍試行

在店家同意之前，不會動正式的 IG 帳號。

10需要店家決定的事
